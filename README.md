# Guitar Coach

免費、手機優先的吉他學習 PWA。

## V2 功能

- 每日 20 分鐘練習路線與連續天數
- 8 堂零基礎學習課程
- 麥克風調音器（E A D G B E）
- 40–220 BPM 節拍器、拍號、Tap Tempo
- 17 種常用和弦圖與搜尋
- 換和弦速度訓練
- 自訂和弦進行循環
- 6 種刷弦節奏練習
- 六條空弦耳訓
- 瀏覽器錄音與回放
- 本週練習、里程碑、等級與智慧建議
- JSON 進度備份 / 匯入
- PWA / 離線快取
- 資料預設只存在使用者裝置

正式網站：<https://ykc1117.github.io/guitar-coach/>


## V2.1 學習強化

- 調音器新增 Guitar / Chromatic 模式
- A4 430–450 Hz 校準
- 六弦 / A4 參考音播放
- 和弦進行自動推測可能調性
- 耳訓新增「兩音音程」
- 新增 0–12 格互動指板
- 大調、自然小調、大小調五聲、Blues 音階顯示
- 指板音符可點擊發聲

### 開源專案研究來源

本版有研究 Guitariz、GuitarBuddy、ChordMini、WebTuner 等公開專案的功能設計方向；實際程式碼以 Guitar Coach 自己的前端架構獨立實作。


## V3.2 課堂筆記 / 老師作業

- 紀錄上課日期、老師、時長、上課主題與重點
- 一行一項輸入老師交代的回家作業
- 未完成作業自動顯示在首頁
- 作業可從首頁或課堂紀錄直接勾選完成
- 課堂筆記可編輯、刪除、回看
- 可紀錄下次上課日期
- 課堂紀錄一併包含在 JSON 備份 / 匯入
