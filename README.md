# Guitar Coach

免費、手機優先的吉他學習 PWA。

## V2 功能

- 每日 20 分鐘練習路線與連續天數
- 8 堂零基礎學習課程
- 麥克風調音器（E A D G B E）
- 40–220 BPM 節拍器、拍號、Tap Tempo
- 17 種常用和弦圖與搜尋
- 換和弦速度訓練
- 自訂和弦進行循環
- 6 種刷弦節奏練習
- 六條空弦耳訓
- 瀏覽器錄音與回放
- 本週練習、里程碑、等級與智慧建議
- JSON 進度備份 / 匯入
- PWA / 離線快取
- 資料預設只存在使用者裝置
