# Guitar Coach

免費、手機優先的吉他學習 PWA。

## V2 功能

- 每日 20 分鐘練習路線與連續天數
- 8 堂零基礎學習課程
- 麥克風調音器（E A D G B E）
- 40–220 BPM 節拍器、拍號、Tap Tempo
- 17 種常用和弦圖與搜尋
- 換和弦速度訓練
- 自訂和弦進行循環
- 6 種刷弦節奏練習
- 六條空弦耳訓
- 瀏覽器錄音與回放
- 本週練習、里程碑、等級與智慧建議
- JSON 進度備份 / 匯入
- PWA / 離線快取
- 資料預設只存在使用者裝置

正式網站：<https://ykc1117.github.io/guitar-coach/>

## Privacy Guard

Guitar Coach 採 local-first 隱私架構：

- 課堂筆記與練習紀錄：LocalStorage
- 課堂照片與錄音：IndexedDB / Blob
- 不使用第三方分析碼、廣告 SDK 或雲端同步
- Runtime 不允許外部 URL、fetch、XHR、WebSocket、EventSource、sendBeacon
- 瀏覽器 CSP 設為 connect-src 'none'，頁面本身禁止對外 API 連線
- Service Worker 只允許 fetch(e.request) 取得目前網站資源
- scripts/privacy-guard.mjs 會在 GitHub Actions 每次 push / PR 自動檢查

## V3.5.1 安全還原

- 新版完整備份使用 SHA-256 完整性驗證
- 還原前先顯示備份日期、課堂數、照片數、錄音數、附件大小與練習時間
- 檔案完整性驗證失敗時禁止還原
- 舊版 V1 完整備份仍可經格式檢查後還原
- 真正按下確認前，不修改目前裝置資料
- 還原前建立本機安全點；若還原中途失敗，會嘗試回復原有 state 與 IndexedDB 附件
